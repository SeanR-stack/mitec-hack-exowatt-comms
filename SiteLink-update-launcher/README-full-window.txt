FULL-WINDOW UPDATE

Stop the running launcher with Ctrl+C. Copy launcher.html from this update into your existing SiteLink-update-launcher folder, replacing only launcher.html. Restart python3 launcher.py and refresh its new local address.

Do NOT replace your builds/ folder or versions.json. Your imported versions stay there. This update ZIP intentionally contains no builds or version index.

Launch now replaces the library with a full-browser-window program. Back to versions closes that session and restores the library. Full screen asks the browser to hide its own chrome; browser support and user permission apply. Esc exits native full screen. Switching still starts a new simulation session.
