FULL LAUNCHER BUNDLE - ALLSUN V20

This folder includes launcher.py, launcher.html, versions.json and builds/. Run it using the README.md instructions. It is not a launcher.html-only patch.

Launch selected version opens a full-browser-window program. Back to versions closes that session and restores the library. Full screen requests native fullscreen; browser support and user permission apply. Esc exits native fullscreen. Switching starts a new session.

If updating an existing local library that contains your own imported builds, back up the entire old folder first. Keep your old builds/ and versions.json together; do not replace your version index blindly. The old launcher can import the new standalone builds/v20.html as a new version without deleting previous imports.

v20 adds the Allsun sun mark. Drone response behavior is unchanged from v19. All bundled older builds remain unchanged.
